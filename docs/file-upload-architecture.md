
**关联关系：**
- Case : Document = 1 : N（一个案件有多个影像材料）
- Document 通过 `case_id` 外键关联到 Case
- Document 的删除策略为 `cascade="all, delete-orphan"`（案件删除时影像记录一并删除）

## 5. API 接口一览

| 方法 | 路径 | 请求格式 | 说明 |
|------|------|----------|------|
| `POST` | `/api/v1/cases/{id}/documents` | `multipart/form-data` | 上传影像文件 |
| `GET` | `/api/v1/cases/{id}/documents` | — | 查询影像列表 |
| `GET` | `/api/v1/cases/{id}/documents/{doc_id}` | — | 获取影像元信息 |
| `DELETE` | `/api/v1/cases/{id}/documents/{doc_id}` | — | 删除影像 |
| `GET` | `/uploads/{case_id}/{filename}` | — | 静态文件访问 |

### 上传请求示例

```
POST /api/v1/cases/1/documents
Content-Type: multipart/form-data; boundary=----xxx

------xxx
Content-Disposition: form-data; name="file"; filename="发票_001.jpg"
Content-Type: image/jpeg

[二进制数据]
------xxx
Content-Disposition: form-data; name="doc_type"

invoice
------xxx--
```

### 上传响应示例

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "id": 1,
    "case_id": 1,
    "doc_type": "invoice",
    "file_name": "发票_001.jpg",
    "file_size": 234567,
    "mime_type": "image/jpeg",
    "created_at": "2024-07-24T10:30:00"
  }
}
```

## 6. 文件存储路径规范

```
data/uploads/
├── {case_id}/
│   ├── {uuid}.jpg          ← 原始图片文件
│   ├── {uuid}.png
│   └── {uuid}.pdf
└── ...
```

- 按 `case_id` 分目录管理
- 文件名使用 UUID 防止冲突和路径穿越
- 原始文件名保留在数据库中用于展示
- 可扩展至 MinIO 存储桶：`starshield-uploads/{case_id}/{uuid}.ext`
